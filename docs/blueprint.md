# **App Name**: Wikidoc Occitanie

## Core Features:

- Dynamic Article Display: View rich-text articles (Markdown, images) with embedded interactive maps for geographic points, 'fiche technique' details, and associated thematic categories.
- Content Creation & Management (CMS): An editor interface for authenticated users (moderators/admins) to create, edit, and publish articles, including uploading images via Cloudinary and inputting map-specific data. Includes revision history.
- Thematic Browsing & Filtering: Browse articles organized by predefined themes (Histoire, Géographie, Nature, etc.) with theme-specific landing pages and interactive filters on the main map view.
- User Authentication & Profiles: Secure user registration, login, and personal profile management using Supabase authentication, including avatar uploads and public bios.
- Community Forum System: Participate in structured discussions through forum categories, topics, and posts, fostering community engagement around regional knowledge.
- Article Interaction (Comments & Favorites): Authenticated users can comment on articles and mark them as favorites for easy access later.
- AI-Assisted Content Moderation Tool: A tool for moderators to efficiently review and manage reported user-generated content (comments, forum posts, articles) with AI potentially flagging content for review based on guidelines.

## Style Guidelines:

- Primary color: Deep, serene blue-green (#316D81) to evoke natural landscapes and historical depth, providing a solid foundation for informational content.
- Background color: A very light, subtle blue-gray (#F0F3F4) to ensure optimal readability for extensive textual content in a bright, inviting scheme.
- Accent color: A vibrant emerald green (#38DB8C) used for interactive elements, calls to action, and highlighting key information, providing clear contrast and energy.
- Headline font: 'Alegreya' (humanist serif) for an elegant, intellectual, and inviting feel in titles and headings, suitable for a knowledge base.
- Body font: 'Inter' (grotesque sans-serif) for clear, modern, and highly readable body text across articles, maps, and interface elements.
- Utilize Lucide icons for their modern, consistent, and scalable vector aesthetics across all interactive and informational elements.
- Implement a responsive, centered-content layout with a focus on a two-column structure for article pages, presenting content alongside interactive maps and technical details for enhanced user experience on all devices.
- Incorporate subtle and smooth animations for transitions, hover effects, and content loading, enhancing user engagement without distraction.
